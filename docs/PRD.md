# 轻右键产品需求文档

版本：1.0（开发前基线）
日期：2026-11-14
状态：需求与设计已整理，已按用户授权开始正式开发，验证状态见 VALIDATION.md。

## 1. 产品目标

为个人 macOS 用户提供免费、本地运行的 Finder 右键工具。用户无需打开独立应用，就能完成新建文件和文件夹、拷贝路径、打开终端、切换隐藏文件显示、常用目录，以及选中项的废纸篓、复制和移动操作。

主应用采用跨平台前端技术。第一版交付 macOS 功能，不承诺同一套代码直接扩展 Windows 或 Linux 的文件管理器。

本文定义产品行为；实现分工见 [ARCHITECTURE.md](ARCHITECTURE.md)，数据结构见 [DB_DESIGN.md](DB_DESIGN.md)，任务见 [PLAN.md](PLAN.md)。

| US-03 | 作为用户，我想直接进入目标目录的终端，避免手动执行 cd。 | F-03 |

## 3. 发布范围

### 3.1 MVP 必须包含

- 原五项核心功能，加上移到废纸篓、复制到、剪切到，以及中文设置窗口和扩展启用引导。
- 系统 Terminal；收藏添加、打开、改名、排序和移除。
- macOS 13 及以上为设计兼容目标，首轮在用户的 macOS 26.6.2 / Apple Silicon 验证。未经测试的系统版本标为未验证。
- 桌面、下载目录、普通本地项目目录；桌面启用 iCloud 同步时按云盘场景处理。
- 本机安装、启用、更新和卸载说明，保留开源声明。

### 3.2 后续迭代

- iTerm2 等额外终端。
- 自定义文本模板和 PPT 有效空白文档模板。
- 收藏导入导出、Intel 构建与兼容性验证。
- 云盘目录兼容性验证；必要时评估工具栏备用入口。
- Windows / Linux 专用右键适配，需要另立需求。

### 3.3 不在本次范围

账号、付费授权、订阅、云同步、埋点、广告、远程数据库、任意命令脚本执行器、系统注入和完整文件管理器。

## 4. 统一上下文规则

| 右键位置 | 新建文件目标 | 拷贝路径目标 | 终端目标 | 添加收藏目标 |
| --- | --- | --- | --- | --- |
| 空白处 | 当前目录 | 当前目录 | 当前目录 | 当前目录 |
| 单个普通文件夹 | 该文件夹内部 | 该文件夹 | 该文件夹 | 该文件夹 |
| 单个文件 | 文件所在目录 | 该文件 | 文件所在目录 | 文件所在目录 |
| 多选文件或文件夹 | 当前浏览目录 | 所选项，按 Finder 返回顺序逐行 | 当前浏览目录 | 当前浏览目录 |

应用包等 Finder 视作文件的包，按文件处理，不在包内部新建文件。搜索结果、“最近使用”等不能确定实际当前目录的虚拟位置，不猜测目录；禁用依赖当前目录的操作。此时若有选中项，拷贝路径、复制到、剪切到和移到废纸篓仍可用；常用目录打开不依赖当前目录。

## 5. 功能需求

### F-01 新建文件（P0）

1. 右键“新建文件”展开类型子菜单：TXT、Markdown、JSON、XML、Shell、Word、Excel、自定义文件名。
2. 选择类型后弹出名称输入框，预填“未命名.扩展名”。自定义项默认“未命名.txt”，允许用户修改扩展名。
3. 创建普通文件；默认不赋予 Shell 文件可执行权限，不自动打开编辑器或执行内容。
4. TXT、Markdown、自定义文件为空白文本；JSON 初始内容为 `{}` 加换行；XML 为 XML 声明和空 root 元素；Shell 为 `#!/bin/sh` 加换行。
5. 文件名不得为空、仅空白、含 `/` 或 NUL，不能为 `.` 或 `..`；以 macOS 文件系统返回结果为最终依据。
6. 同名自动编号，如“未命名.md”“未命名 2.md”；原文件内容保持不变。创建后在 Finder 选中新文件。
7. 取消输入不创建文件。权限不足、目录不存在或写入失败应说明原因，不伪报成功。
8. 首版增加用户提供的 Word（.docx）和 Excel（.xlsx）空白模板，复制有效文件内容创建；对项目副本去除作者元数据，原始模板不修改。PPT 暂不支持。

### F-02 拷贝路径（P0）

复制绝对 POSIX 路径到系统剪贴板；中文和空格保持原样，多选使用换行分隔。不默认附加 Shell 转义、不替换为波浪号、不对文件内容进行读取。

### F-03 在此打开终端（P0）

MVP 使用系统 Terminal，在目标目录打开会话。验收必须检查会话中的 `pwd`，仅启动 Terminal 不算完成。不存在或无权限的目录给出提示，不回退到用户主目录冒充成功。

### F-04 隐藏文件显示（P0）

提供“显示所有隐藏文件”和“隐藏所有隐藏文件”两个菜单项。修改 Finder 的全局显示状态，不重命名文件、不修改隐藏属性、不递归遍历磁盘。

首次启用引导说明作用范围。显示刷新若需要重启 Finder，应在操作前说明并让用户选择继续或取消；支持直接刷新时无需额外确认。不在安装、启动或测试中擅自切换设置。

### F-05 常用目录（P0）

1. 支持“添加到常用目录”；空白处文案为“添加当前目录到常用目录”。设置页也可通过目录选择器添加。
2. 默认名称取目录名，根目录使用卷名。用户可修改收藏名称，真实目录名不变。
3. 同一标准化路径不重复添加；已存在时提示已收藏。MVP 不将不同路径的符号链接自动合并。
4. “常用目录”子菜单按用户顺序显示；点击后由 Finder 打开目标目录。不承诺复用原窗口或新建标签页。
5. 设置页支持改名、上移、下移、移除。收藏名称可重复，设置页显示完整路径以区分。
6. 收藏保存到本机，重启应用和系统后保留。
7. 目录被移动、删除或磁盘未挂载时，提供重新定位、移除收藏、取消。重新定位必须由用户选择目录，不自动搜索磁盘。
8. 移除收藏只删除记录；没有收藏时显示禁用的“暂无常用目录”和可用的管理入口。

### F-06 设置和应用生命周期（P0）

设置页包含扩展状态与启用引导、菜单开关、终端显示、常用目录管理、版本和开源声明。读取不到扩展状态时显示“未知”，不当作已启用。

打开应用或管理入口时显示设置；关闭窗口后销毁设置 WebView，保留右键能力。动作执行不应创建设置 WebView。是否保留轻量宿主进程由技术验证确定，不能用隐藏窗口代替释放资源。

### F-07 移到废纸篓（P0，2026-11-15 补充）

仅对明确选中的文件/文件夹操作，多选逐项处理。使用系统废纸篓 API，可由用户在 Finder 废纸篓中恢复；不提供永久删除，不使用 rm。空白处禁用，不把当前目录误当作待删对象。无权限或不支持废纸篓时说明失败，不退化为直接删除。

### F-08 / F-09 复制到、剪切到（P0，2026-11-15 补充）

- 右键菜单各提供独立子菜单：常用目录列表 + “选择其他目录…”。收藏通过 ID 查询最新路径。
- 仅对明确选中的项操作；空白处禁用。搜索结果有明确选择时也可操作，不依赖虚拟容器路径。
- 复制保留源项；剪切成功后源项移到目标位置。这是直接移动，不改变系统剪贴板。
- 同名自动编号，不覆盖目标文件；同目录移动提示已经在目标目录，不擅自重命名源文件。
- 不允许文件夹进入自身或子目录；取消选择目录不执行操作。
- 后台执行，不阻塞设置界面。全部成功使用短暂完成提示；部分失败说明成功/失败数量及失败项，不将部分完成伪报为全部成功。
- 移动失败不进行自定义“复制后强行删除”回退；源数据保留由系统结果决定，不承诺跨卷事务回滚。

### F-10 菜单小图标（P0）

Finder 右键主菜单和可操作子菜单均显示小图标。新建、路径、终端、废纸篓、复制、剪切、显示/隐藏、收藏、设置分别使用对应系统图标；目录项使用文件夹，文件类型采用系统关联应用的文档类型图标。浅色/深色均可辨识；菜单位图固定 16pt / 32px，避免复制高分辨率应用图标造成菜单卡顿。此项不是仅指设置页图标。

### F-11 新建文件夹（P0，2026-11-15 补充）

Finder 菜单提供“新建文件夹”和文件夹加号图标。目标目录与新建文件的上下文规则相同；输入名称后创建一层目录，默认“新建文件夹”。同名文件或目录存在时整体名称自动编号，例如“项目.v1 2”，不覆盖、不自动递归创建父目录。取消不创建，完成后选中新目录。空名称和路径分隔符按文件名规则拒绝。

### F-12 启动与后台设置（P0，2026-11-15 补充）

| 开关 | 默认 | 行为 |
| --- | --- | --- |
| 显示菜单栏图标 | 关闭 | 开启后在系统菜单栏显示小图标，提供打开设置与退出；关闭不停止后台功能 |
| 随系统启动 | 关闭 | 用户主动开启时注册本应用为 macOS 登录项；登录后静默启动，不弹设置、不占 Dock |
| 关闭设置后在后台静默运行 | 开启 | 关闭设置窗口销毁 WebView，轻量宿主继续处理右键；关闭此项后设置窗口关闭或动作完成即退出宿主，右键仍可按需启动 |

三个开关独立保存。开机启动实际状态以系统登录项授权为准，显示已启用/已关闭/需要确认/不可用，不能只凭数据库值声称已启用。需要授权时提供系统登录项设置入口，注册失败明确显示错误。手动打开应用、右键设置入口或菜单栏设置入口均能打开设置。显式“退出轻右键”总能退出，不受后台开关阻止。进行中的文件复制/移动不能因关闭设置而中断；非驻留模式等待动作完成后退出。

## 6. 非功能需求

| 编号 | 要求 | 验证方式 |
| --- | --- | --- |
| NFR-01 | 界面简体中文，跟随系统浅色/深色，原生 Finder 菜单 | GUI 手动检查 |
| NFR-02 | 离线可用；不依赖账号、服务端、Node.js 或独立数据库服务 | 发布包在离线环境启动 |
| NFR-03 | 正常空闲不轮询目录、不扫描磁盘；设置关闭后不保留其 WebView | 进程及资源检查 |
| NFR-04 | 不覆盖已有文件；所有路径通过参数或系统 API 传递 | 文件内容前后比对和路径测试 |
| NFR-05 | 不要求关闭 SIP；权限按实际操作申请，不以全盘访问替代权限设计 | 安装和权限检查 |
| NFR-06 | 数据和日志留在本机；不记录剪贴板内容、文件内容及完整用户路径 | 静态检查与运行日志检查 |
| NFR-07 | 安装/卸载不修改系统隐藏设置，不删除用户文件；默认保留收藏配置 | 安装卸载回归 |

首版性能预算为工程评审目标，不是已测结论：发布安装包不超过 30 MiB、安装后应用不超过 60 MiB；静置 60 秒后相关进程合计 CPU 平均低于 1%；菜单构建在 100 条收藏下 p95 不超过 100 ms。菜单耗时指扩展构建时间，不包含 Finder 自身弹出时间。内存需分别记录扩展、动作宿主、WebView 的打开前/打开后/关闭后数据。超预算须说明依赖与测量方法，再调整设计或预算，不能直接写“轻量”。
