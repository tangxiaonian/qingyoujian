# 轻右键开发计划

起草：2026-11-14；实现及补充需求：2026-11-15。用户已授权正式开发、测试及新建公开仓库上传。已完成正式工程、当前功能实现与主要自动化/集成检查；本机预览版进入公开源码交付。完整人工验收状态见 VALIDATION.md。

## 1. 交付顺序

M0 技术可行性 → M1 正式工程与数据基础 → M2 九项 MVP 功能 → M3 验收交付 → I1 迭代体验 → I2 扩展兼容性。

不先花时间装修完整设置页。先证明真正的 Finder 菜单、可信动作传递和无 WebView 动作执行成立，再完成产品。估算与排期在 M0 后给出，不把集成未知项伪装成确定工期。

## 7. 进度与变更管理

每完成阶段，更新本文件任务状态和验证记录，注明代码完成、编译通过、逻辑测试通过或 GUI 通过的不同证据。新增功能先补 PRD；接口/表变更同步架构和数据设计。未经用户授权，不提交、推送、安装或启用扩展；本次新建公开仓库上传已明确授权。
