# 0.1.0 验证记录

开始：2026-11-14；持续到 2026-11-15。macOS 26.6.2 / Apple Silicon，Xcode clang 21，Node 24.14.0，Rust 1.100.0。

## 已完成的检查

- `npm run build`：vue-tsc 与 Vite 生产构建通过。
- `npm run lint`：通过。
- `npm run test -- --run`：2 项通过（收藏排序、结构化错误消息）。
- `cargo check`：通过。
- `cargo test`：7 项通过（不覆盖/真实模板、新建目录、目录规则、复制/移动、可恢复废纸篓、SQLite 收藏及启动偏好重启保存）。
- `cargo clippy --all-targets -- -D warnings`：通过。
- 原生菜单逻辑测试：菜单复制后的整数标记、稳定收藏/类型 ID、空白菜单不使用过期选择，均通过。
- 原生命名框测试：真实 AppKit 对话框的 UTF-8 名称返回和取消语义通过；原生菜单栏图标显隐和模拟登录/手动启动分流通过。
- Office 模板：ZIP 校验、全部 XML 可解析、无外部链接；正文/单元格为空白，作者与编辑者元数据已从项目副本清除。原始文件未修改。
- 前端浏览器预览：通用页、收藏空态和导航已检查。浏览器不提供本机动作，不能用它证明 Tauri/Finder 集成有效。

## 集成与发行检查

- release 应用包构建与内外层签名校验通过，扩展已注册启用并实际加载。
- 已签名扩展的冷/暖请求可调用 Rust 宿主；来自普通 open URL 的测试请求未写入数据库。
- 实际冷启动添加收藏成功，宿主处于 Accessory 模式且没有可见设置窗口；普通打开能显示设置。
- 签名动作端到端验证：收藏目的目录 → 复制文件 → 同名移动自动编号 → 移到系统废纸篓，均通过。仅使用自建临时样例。
- Terminal 会话 cwd 通过 lsof 核对，中文与空格路径正确。
- SMAppService 注册成功后状态为 enabled，取消后恢复 disabled。首次 status=notFound 并不阻止注册；UI 保留尝试入口。未进行真实注销/重登录。
- 100 个收藏、30 次原生菜单构建样本 p95 约 4.0～6.2ms；属于测试进程中真实菜单构建，不含 Finder 弹出和系统响应时间。
- 原生菜单截图由实际扩展菜单代码在测试进程渲染获得，不冒称 Finder 鼠标操作验收。

## 最终安装与静默运行

- 安装位置为当前用户 Applications 下的轻右键.app，扩展标识 local.qingyoujian.extension；插件注册仅一条。测试生成的收藏已清理，不上传本机数据库。
- 实际验证：后台关闭时，签名右键动作完成后宿主退出；后台开启时，宿主保持 Accessory 且无可见设置窗口。
- 完整功能构建静置采样 60.05 秒，宿主与两个扩展进程累计 CPU 时间未增加（测量分辨率内平均 0.0%）。采样末宿主 RSS 53.95 MiB，两个扩展各 22.48 MiB。RSS 包含共享映射，不能将其简单相加视为实际独占物理内存。
- 当前本机 release 应用包约 9.8 MiB；最终归档大小以实际生成文件为准。
- 后续图标/格式整理没有新增后台轮询或服务。生成代码与依赖缓存不上传。
